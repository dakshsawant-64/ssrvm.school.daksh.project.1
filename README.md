# School Project Sales Website

## Overview

This project is a school exhibition website created using **HTML, CSS, and JavaScript**. It demonstrates a simple online shop where visitors can browse products and click buttons to view detailed information about each item.

The website was developed as a learning project to practice front-end web development, including page layout, styling, JavaScript programming, and user interaction.

---

## Features

* Home page with a clean and simple layout.
* Two different shops with multiple products.
* Product buttons that display detailed information using JavaScript alerts.
* Product details include:

  * Shop Name
  * Product Name
  * Category
  * Price
  * Stock Available
  * Difficulty
  * Age Group
  * Materials Used
  * Features
  * Purpose
* Contact information for each shop.
* Responsive and easy-to-use interface.

---

## How It Works

1. Open the website in a web browser.
2. Browse the available shops.
3. Click any product button.
4. A JavaScript alert displays detailed information about the selected product.
